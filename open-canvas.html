[ 为什么需要 ]

信息碎片化 · 工具割裂 · 数据隐私

信息分散在多个工具

  1. 笔记在 Notion，待办在 Todoist，日程在日历
  2. 灵感、图片、PDF 散落在不同文件夹
  3. 切换成本高，难以形成全局视图

数据不在自己手中

  1. 云服务依赖网络，断线即不可用
  2. 隐私数据存储在第三方服务器
  3. 导出困难，迁移成本高昂

[ 三端一体 ]

浏览器 · Obsidian · API 同一套工作区
[01] 浏览器应用

独立 Web 应用

一条命令启动本地服务，打开浏览器即可使用。6000×4000 无限画布，自由拖拽与缩放。

[02] Obsidian 插件

深度融入知识管理

作为 Obsidian 原生插件运行，与你的笔记库无缝衔接。在知识图谱旁管理待办和日程。

[03] API 服务

程序化操作画布

内置 RESTful API 和 CLI 工具链，支持脚本、AI Agent 自动创建卡片、追加笔记、查询状态。

[ 使用场景 ]

为不同角色设计的工作方式
[01]

每日工作台

打开画布，看到今天的待办、日程和灵感笔记。一张画布掌控全天工作节奏。

角色: 个人用户
[02]

项目管理

为每个项目创建一个 Grid，汇集相关笔记、资料和任务。多画布切换，井井有条。

角色: 团队负责人
[03]

灵感收集

在浏览器中快速记录灵感，回到 Obsidian 中深度整理。拖入图片和 PDF，资料一目了然。

角色: 创作者
[04]

AI 自动化

通过 API 让 Agent 自动为你创建待办、追加笔记。预留 AI 联动接口，扩展无上限。

角色: 开发者
